Here is a targeted cheat sheet for [VS Code](https://code.visualstudio.com/), optimized specifically for Front-End Development (HTML, CSS, JavaScript, and TypeScript).

## 🎨 Front-End Power Shortcuts
These shortcuts speed up the specific workflows of building UI and styling elements.

| Action | Windows / Linux | macOS |
|---|---|---|
| Trigger Emmet Expansion (e.g., type div.card>ul>li*3 + key) | Tab (or Ctrl + E) | Tab (or ⌃ + E) |
| Toggle Word Wrap (Crucial for long HTML/SVG lines) | Alt + Z | ⌥ + Z |
| Open Live Server Preview (Requires Live Server extension) | Alt + L then Alt + O | ⌘ + L then ⌘ + O |
| Format Document (Prettier / CSS / HTML alignment) | Shift + Alt + F | ⇧ + ⌥ + F |
| Show CSS/JS Suggestions / Auto-complete | Ctrl + Space | ⌃ + Space |
| Show Hover Definition (See CSS specs or JS types) | Ctrl + K then Ctrl + I | ⌘ + K then ⌘ + I |

## ✍️ Multi-Cursor & Code Editing
Write layout variations or rename multiple classes simultaneously.

| Action | Windows / Linux | macOS |
|---|---|---|
| Insert Multi-Cursor (Click anywhere to type in multiple places) | Alt + Click | ⌥ + Click |
| Add Cursor Above / Below (Great for lists or CSS rules) | Ctrl + Alt + Up / Down | ⌥ + ⌘ + Up / Down |
| Select Next Match (Highlight and edit identical class names) | Ctrl + D | ⌘ + D |
| Move Line Up / Down (Reorder HTML tags or CSS properties) | Alt + Up / Down | ⌥ + Up / Down |
| Duplicate Line Up / Down | Shift + Alt + Up / Down | ⇧ + ⌥ + Up / Down |
| Toggle Line Comment (<!-- --> or /* */ or //) | Ctrl + / | ⌘ + / |


## ⚡ Recommended Extensions for Front-End
If you want to turn VS Code into the ultimate front-end environment, install these from the Extensions tab (Ctrl+Shift+X / ⌘+⇧+X):

* Prettier - Code formatter: Automatically fixes alignment, quotes, and semi-colons on save.
* Live Server: Spawns a local development server with live reload for static HTML/CSS/JS.
* Tailwind CSS IntelliSense: Adds autocomplete, linting, and hover previews for Tailwind utility classes.
* Auto Rename Tag: Automatically renames paired HTML/XML tags when you change the opening or closing one.
